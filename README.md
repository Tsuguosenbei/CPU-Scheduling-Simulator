# CPU Scheduling Simulator

A PT 101 group project developed using Python and Tkinter.

## Scheduling Algorithms
- First Come, First Served (FCFS)
- Shortest Job First (SJF)
- Shortest Remaining Time First (SRTF)
- Non-Preemptive Priority Scheduling

## Group Contributions
This repository will contain contributions from four group members, with each member committing their own work.
